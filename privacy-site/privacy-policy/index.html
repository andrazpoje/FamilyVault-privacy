Privacy Policy

Last updated: September 23, 2026

FamilyVault / Družinski sef

FamilyVault / Družinski sef is an Android app for storing important family information, document metadata, attachments, and reminders locally on the user's device.

This privacy policy explains how the current version of the app handles data.

Data storage

The current version stores data locally on the user's device by default.

The app may store:

  • family member names
  • birth dates
  • relationship/category information
  • notes entered by the user
  • tax numbers
  • EMŠO numbers
  • document metadata
  • document expiration dates
  • reminder rules
  • PDF or image attachments selected by the user
  • profile photos selected by the user
  • app settings, including app lock and screenshot protection settings

Attachments selected by the user are copied into app-private storage on the device.

The local Room database is encrypted. Attachments and profile photos are encrypted in app-private storage.

Attachments are encrypted at rest. When the user opens an attachment, FamilyVault prepares a temporary decrypted file in a limited cache area and shares it with the selected external app through FileProvider. The external app is not part of the FamilyVault security model. Automatic cleanup is limited to these regenerable decrypted cache copies and exactly named legacy plaintext inner-ZIP temporary files from the older encrypted-export flow. Cleanup does not automatically delete the durable database, local keys, encrypted attachments, encrypted profile photos, or backup exports created by older versions.

If the user chooses Add to calendar, FamilyVault opens the selected calendar app with basic expiry-date information. Calendar events are no longer protected by the FamilyVault security model and depend on the selected calendar app and the user's sync settings.

Data collection

The current version does not transmit family data, document data, attachments, tax numbers, EMŠO numbers, or reminder data to a developer server.

The current version does not include:

  • cloud sync
  • user accounts
  • shared family spaces
  • analytics
  • advertising
  • OCR or AI processing
  • premium/subscription account processing
  • restore/import

Data sharing

The current version does not automatically share user data with the developer or with third-party services.

User-initiated actions such as opening attachments in external apps or adding an expiry date to a calendar app can move selected data outside FamilyVault's local security model.

Encrypted backup export is temporarily unavailable in FamilyVault 0.2.0-beta.1. Direct plaintext ZIP export and restore/import are also unavailable. Cloud sync and user accounts are not available.

App permissions

The app may request permissions required for its features, such as notification permission on Android 13 and newer.

The app uses file access flows selected by the user to attach documents. Adding an expiry date to a calendar uses Android's calendar insert intent and does not require WRITE_CALENDAR permission.

App lock and screenshot protection

The app includes an optional app lock using Android biometric/device credential features.

The app also includes optional screenshot protection. When enabled, the app attempts to prevent screenshots and screen recording through Android system window security flags.

These features help protect access to the app, but they are not a replacement for full device security or secure backups.

Data retention

Data remains stored locally on the user's device until the user deletes it in the app or uninstalls the app.

Backup files previously exported by older versions remain wherever the user saved or shared them.

Data deletion

Users can delete family members, documents, reminders, and attachments through the app where supported.

Some deletion actions may be blocked when related records still exist, to prevent accidental data loss.

The app does not currently create user accounts, so there is no account deletion flow. Local data can be deleted in the app where supported, by clearing the app's data in Android settings, or by uninstalling the app. Backup/export files previously created outside the app must be deleted by the user from the location where they were saved.

Children's data

The app can store information about family members, including children, when the user manually enters it.

The app is not currently designed as a child-directed service and does not create child user accounts.

Security

The current version is a local-first build.

The local Room database, attachments, and profile photos are encrypted at rest. Encrypted backup export is temporarily unavailable in this beta; direct plaintext ZIP export and restore/import are unavailable. External calendar apps and external PDF/image viewers are outside the FamilyVault security model after the user chooses to hand selected data to them. The local security model assumes Android's app sandbox and a non-compromised app process; a rooted device, compromised same-UID component, or malicious native code in the app process is outside that model. Users should keep their device protected with a secure lock screen.

Changes to this policy

This policy may be updated as the app adds new features or changes behavior, such as restore/import, cloud sync, user accounts, family sharing, storage/security changes, OCR/AI, analytics, or subscriptions.
